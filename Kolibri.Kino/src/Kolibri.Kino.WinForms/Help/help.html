Prerequisites (works best if you have these API keys)

Kino gets movie and series details from online services, and each of them wants a key. Get your own free keys before you start using Kino for real, and enter them in File → Settings…. The keys are stored in your database, so SilverScreen uses them too. Keep them to yourself, like passwords.

Default test keys. Kino comes with shared test keys for OMDb and TMDb, used until you enter your own. They let you try Kino at once, but everyone using them shares the same daily limit (OMDb allows 1,000 lookups a day per key), so searches, imports and scans can stop early with an error. The yellow bar in the search window tells you when the test keys are in use. SubDL and Plex have no test keys.

OMDb key (omdbapi.com)

  1. Go to https://www.omdbapi.com/apikey.aspx.
  2. Choose FREE (1,000 requests a day), enter your e-mail address, name and a short note on use (e.g. "personal movie library"), and submit.
  3. You get an e-mail with the key and an activation link. Click the activation link: the key doesn't work until you do.
  4. Paste the key into Settings → OMDb key and click Test connections.

Want more than 1,000 requests a day? OMDb's paid Patreon tiers give a higher limit.

TMDb key (themoviedb.org)

  1. Create a free account at https://www.themoviedb.org/signup and confirm your e-mail address.
  2. Open https://www.themoviedb.org/settings/api (your profile → Settings → API).
  3. Request an API key, choose Developer (personal use), accept the terms and fill in the short form. For the application URL, any address of yours will do.
  4. Copy the API Key (the short one, not the long "API Read Access Token") into Settings → TMDb key, and test.

SubDL key (subdl.com)

  1. Create a free account at https://subdl.com and log in.
  2. Open your account panel and its API page, then copy the API key with its copy button.
  3. Paste it into Settings → SubDL key, and test.

SubDL limits each key to a number of calls a day, so use a key of your own. Kino uses it for the Subtitles button in the details window, and SilverScreen uses it too.

Plex token (X-Plex-Token) and server name

The token lets Kino read your Plex libraries and playlists. It is as powerful as your Plex user name and password together.

  1. Open the Plex web app on your Plex server: http://<server>:32400/web, e.g. http://HTPC:32400/web, and sign in. (The token isn't shown on app.plex.tv.)
  2. Open any movie in a library, click ⋯ (More) → Get Info, then View XML.
  3. A new tab opens with XML. At the end of its address is X-Plex-Token=…: copy the value after the =.
  4. Paste it into Settings → Plex token, and enter the server's network name (e.g. HTPC) as Plex server name. Kino connects to http://<name>:32400. Then test.

Plex's own guide: Finding an authentication token / X-Plex-Token. A token found this way can stop working, e.g. when you sign out of all devices or change your Plex password; then fetch a new one the same way.

First start

  1. Open File → Settings….
  2. Under LiteDB file, choose where your database is, or where a new one should be (see The database).
  3. Enter your own OMDb and TMDb keys, and the Plex server and token if you use Plex.
  4. Click Test connections, then Save.

Until you enter your own keys, Kino uses the shared test keys, with limited lookups.

The database

Everything Kino knows (movies, file links, series, watchlists, your settings) is in one LiteDB file, normally SilverScreen.db. Posters are cached next to it in SilverScreen.imgdb. SilverScreen and Kino can use the same file at the same time.

Kino finds the database in this order:

  1. The file you chose in Settings → LiteDB file (remembered in %LOCALAPPDATA%\Kolibri.Kino\usersettings.json).
  2. Otherwise Kino:LiteDbPath in appsettings.json next to the program, the default for a first start.
  3. If that database names another existing database file in its settings, that one.

To move to another database, enter a file or a folder under LiteDB file in Settings, e.g. E:\RELEASE\SilverScreenDB (a folder means SilverScreen.db in it). The folder must exist. If it has no database, Kino asks before making a new, empty one. The change takes effect after a restart; Kino offers to restart at once. Help → About shows the database in use.

Settings

File → Settings… edits your user settings, stored in the database for your Windows user name and shared with SilverScreen.

  • General: the database file (see The database) and your favorite watchlist, opened by default.
  • Movie services: the API keys. Empty OMDb/TMDb keys mean the shared test keys.
  • Plex: server name and token.
  • Folders: where your movies and series are; Local movies starts in the movies folder.

Test connections tries the OMDb, TMDb and SubDL keys and the Plex token without saving. New keys apply at once after Save.

Search library and OMDb

Library → Search library and OMDb opens at start and lists your library.

  • Type a title and press Enter or Search library to search what you have; Search OMDb searches online.
  • Select an online result and click Import selected to add it to your library.
  • Filter by type with the buttons above the list, sort with the Sort options, or click a column header.
  • Double-click a row for all details: plot, ratings, cast, poster, and Play / Open on disk when you have the file.
  • Right-click a row to open it on IMDb or TMDb, open the file's folder, or remove it from the library.
  • Add to watchlist… puts the selected title on a watchlist.

Subtitles (in the details window)

The Subtitles button shows whether the movie file has subtitles, as in SilverScreen:

 green a .srt with the movie's name next to it (e.g. Movie.srt, Movie.en.srt). Click to show it.
 light blue a Subs folder with subtitle files (e.g. downloaded from SubDL), but no .srt with the movie's name next to it. Click: if one in Subs is for this release, it's copied next to the movie with the movie's name and the button turns green; if none is, Kino lists them all by size, largest first and selected (often the right one). Use selected (or a double-click) copies the one you pick next to the movie (green); Cancel changes nothing.
 light orange none found, but the file is an .mkv, which often has subtitles built in.
 salmon none found.

Without subtitles, a click downloads them from SubDL: every subtitle SubDL has for the movie (by IMDb id) in your Subtitle languages (Settings, default NO,EN) is unpacked into the Subs folder. If one is for your release, it's copied next to the movie with the movie's name at once (green); otherwise Kino offers the largest, as above. A subtitle is "for your release" when its name starts with the movie file's name (e.g. Movie.1080p.WEB-GRP.en.srt), or has the same release group (GRP, after the last -). Subtitles are timed to one release, so others may be out of sync. Needs a SubDL key. The button is off when the title isn't linked to a movie file.

IMDb ratings are coloured: red below 6, orange from 6 to 6.9, green from 7.

Local movies

The movie files in a folder and how they match your library.

  • Browse… picks the folder. All / Missing on disk / Not in library filter the list.
  • Double-click a movie for its details window (as in the search window); double-click a file that isn't in the library to find the movie for it.
  • Scan new files matches new video files to movies; Scan all + refresh details also fetches the details again. A scan tries, in order: an IMDb id in the file or folder name ({imdb-tt1234567}), your library, Plex, TMDb and OMDb. The scan report lists what was linked and what wasn't.
  • Find movie for file… (or Find movie… in the scan report) lets you search and pick the right movie for a file the scan couldn't match. Its Open on IMDb opens IMDb in a window in Kino: the selected movie, or, when nothing was found, IMDb's own search for your text. Find the movie there and click Use tt…: its IMDb id goes into the search, and the movie is found.
  • Remove missing… removes links to files that no longer exist; the movie details are kept.
  • Clean up folder… deletes leftover files (.nfo, .txt, foreign subtitles …) after asking. They are deleted permanently. Video files are never deleted.

Check the cleanup list before you scan. Which files are deleted (after a scan, and with Clean up folder…) is the list Kino:Cleanup:FilePatterns in appsettings.json next to the program. It deletes subtitles in many languages, for example Bulgarian, Russian, Greek, French, German and Spanish. If you speak one of them, remove its lines from the list, or those subtitles are deleted too. For Bulgarian, remove both "Bulgarian.srt" and "bul.srt"; most languages are listed both by name and by a three-letter code (e.g. "german.srt", "deu.srt" and "ger.srt"). Remove a line with its comma, keep the rest of the list as it is, and restart Kino. Kino:Cleanup:AfterScan decides when it runs: Ask (the default: list the files and ask first), Always or Never.

Local series

  • Select a series to see its seasons and episodes, one tab per season. Episodes you have on disk are green; double-click to play.
  • Episode details are fetched once and remembered. Refresh episodes fetches them again (TMDb gives the most; without a TMDb key, OMDb).
  • Files are matched to episodes by names like S01E02, 1x02 or Episode 6 in a Season 2 folder.
  • Find new series… looks through the series folder for series not in the library and asks about the ones it can't match.
  • Set folder… links the selected series to its folder. Right-click a series to change its IMDb id or open it on IMDb.

Watchlists

  • Choose a list, or make one with New list…. A movie is on one list at a time; adding it to another list moves it.
  • Mark watched / Mark not watched, and filter with All / Not watched / Watched.
  • Copy copies the list to the clipboard (pastes into Excel), Export CSV… saves it as a file.
  • Copy to Plex playlist adds the movies to the Plex playlist of the same name (made if missing). Needs the Plex token.

API usage report

Help → API usage report (or the button in Help → About) shows how many calls Kino has made to OMDb, TMDb, SubDL and Plex, and how many of them failed. The services don't tell how many calls you have left, so Kino counts its own.

  • Show: the last 30 days (per day), a month (per day), a year (per month) or everything (per month). The line at the top shows today.
  • OMDb's free keys allow 1,000 calls a day; days above that are red. Failed calls are often "Request limit reached" or a wrong key (see Prerequisites).
  • TMDb has no daily limit, only a limit per second. Plex is free; it's counted so you can see how much a scan uses.
  • Every Kino using the same database is counted (also the web version, if it uses this file). SilverScreen's calls are not counted, and with the shared test keys, other people's calls aren't either.
  • The counts are kept in the database (collection KinoApiUsage, one entry per day) and saved every half minute and when Kino closes.

Log

Help → Log (or the button in Help → About) shows what Kino has done: the messages each window showed in its status bar, errors with their details, and what Kino's controllers reported (e.g. "Settings saved"). Use it to find out what went wrong, and when.

  • Show today, the last 7 or 30 days, or everything kept; Level picks errors only, warnings and errors, information and up, or everything; type in the search box and press Enter to find a title, a file or a message.
  • Errors are red, warnings orange. Select a line to see all of it below, with the error's details.
  • The log is its own database next to the library (SilverScreen.logdb, as the posters are in SilverScreen.imgdb). Entries older than Kino:LogRetentionDays in appsettings.json (30) are deleted.
  • Which levels are written is set by Logging:LogLevel:Default in appsettings.json: Information (the default) writes results and errors; Debug also writes work in progress ("Scanning 12 of 340 …"), which makes the log much longer; Warning only problems.
